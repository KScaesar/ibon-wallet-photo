# 7-11 ibon 2×3 吋皮夾照 4 合 1 排版工具

> 將 4 張生活照（支援直式與橫式混搭）自動排版為符合 7-11 ibon 4×6 特殊相片紙規格（10 × 14.8 cm，300 DPI）的單張輸出圖，並附帶微白邊與裁切輔助導線，兼具原生構圖完整性與高精度手工剪裁。

---

## 快速開始 (Quickstart)

```bash
# 準備 4 張照片命名為 photo1.jpg ~ photo4.jpg 置於當前目錄
uv run build.py
```

執行後腳本會自動根據排版規則，同時在當前目錄產出以下兩個規格檔案：
- `ibon_print.jpg`：**（推薦）** 專為 7-11 ibon 實體相紙（10.0 × 14.8 cm，300 DPI）調校之精準滿版檔。
- `standard_4x6.jpg`：標準英制 4×6 吋（1800 × 1200 px，3:2 比例）通用相片沖印備用檔。

## 核心產出規格

- **推薦輸出檔（ibon 專用）**：`ibon_print.jpg`（1748 × 1181 px，對應 10.0 × 14.8 cm 300 DPI，含 1.5 mm 白邊與中央虛線）
- **通用備用檔（英制 4×6）**：`standard_4x6.jpg`（1800 × 1200 px，標準 4×6 吋 3:2 比例，供一般相館與其它沖印機使用）
- **核心排版腳本**：[build.py](./build.py)（執行一次即可自動同時產生上述兩款規格檔案）
